# 《文案手册》与数值校准需求清单（T0.6 提请）

- **提请日期**：2026-09-28（M0 收尾，依据 [development-plan.md](development-plan.md) T0.6）
- **提请对象**：主创（内容与数值最终裁定方）
- **依据**：《ChiliCraft·插件版技术文档（实现规格 v1.1）》——「数值与文案以总纲 v4.0 与《文案手册》为准」「歌词文案与具体数值初值需实测校准」

## 四、交付方式

- **格式**：优先 YAML 键值（键位与中文注释已预留，照注释填值）；也可先给任意格式草稿（文档 / 表格），由开发侧转录；
- **生效**：每批交付后替换对应 yaml → `/cc reload`（内容文件更换重启）→ 开发侧回归一次显示效果；
- **节奏**：M1 / M2 / M3 / M5 前各一批，每里程碑收尾同步一次本清单勾稽状态。
